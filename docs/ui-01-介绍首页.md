## 视觉设计

| 项目 | 设计 |
|---|---|
| 背景 | 白色 `#ffffff`，右侧淡冰蓝空间光感与细网格 |
| 文字 | 深蓝 `#18354a` 为主，蓝灰 `#60768a` 为辅 |
| 强调 | 蓝色 `#176eaa` 用于入口与轨迹，少量青蓝表示核验分支 |
| 排版 | 标题优先使用 Noto Sans SC（思源黑体）800 字重，正文使用等线，拉丁字与步骤号使用 Bahnschrift；左侧介绍和操作，右侧资金轨迹主视觉 |
| 主视觉 | 银行、微信、支付宝三路记录沿蓝色轨迹汇入白色玻璃分层账页，再关联金额核验与来源定位 |
| 动态 | 资金光点沿路径流动，按钮对悬停和点击作反馈；系统减少动态效果时停用持续动画 |
| 下方内容 | 三项功能概览与四步使用流程，属于介绍页面内容，不作为额外业务功能 |
| 窄窗口 | 逐步收拢间距，小屏改为上下排列；介绍页自身可滚动 |

介绍页采用白色科技风格，承担软件介绍与展示；工作台保持现有紧凑办公布局，承担实际操作。前次实现只修改介绍页配色、字体与主视觉，工作台样式未重做。字体使用本机已安装字体并设后备字体，无需联网；其他电脑缺少对应字体时会使用后备字体。介绍中的轨迹为概念示意，不展示真实案情或编造性能数字。

## 启动与返回规则

| 情况 | 行为 |
|---|---|
| 首次打开、未保存跳过选择 | 显示介绍首页 |
| 未勾选并点击进入 | 进入案件工作台，下次仍显示介绍 |
| 勾选「下次打开跳过介绍页」并点击进入 | 保存选择，下次直接进入案件工作台 |
| 仅勾选、未点击进入 | 尚未保存 |
| 工作台 → 使用说明 → 查看软件介绍 | 重新显示介绍，不自动修改已保存选择 |
| 使用说明勾选「打开时显示软件介绍首页」 | 立即恢复下次先显示介绍 |
| 已保存跳过，但显式打开 `#intro` 或介绍章节 | 仍允许查看介绍 |
| 浏览器禁止存储或存储写入失败 | 保持可进入工作台，明确提示偏好无法保存 |

启动偏好使用浏览器本地存储，键名为 `fundsift.skipIntro.v1`。它只保存一个布尔选择，不保存案件材料、账号或业务记录。HTML 文件在不同浏览器或不同路径中的存储隔离规则可能不同，不将其等同于最终 EXE 的应用设置。

返回介绍时清理工作台弹窗、流水详情和提示，避免业务浮层覆盖介绍页。隐藏页面不可键盘交互；进入与返回时将焦点移到当前页面。介绍页的章节链接及浏览器前进、后退路径均已纳入逻辑检查。
