# 06 · M0 加固与介绍页修复交付

> 实施日期：2026-11-13～2026-11-14；桌面版本：0.1.1。本文记录前一聊天中已批准、但中断的 M0 加固和介绍页修复。实际验证结果在下文单独登记。

## 1. 范围与已确认口径

在原 M0 桌面骨架上补齐版本迁移、升级备份、数据库基础不变量、统计摘要、异常诊断、编号和目录规则。另修复介绍页滚动，增加点击“进入工作台”后的退场与浮现动画。

- 备份按升级批次保留，不自动删除。工作区索引与案件分别升级，不宣称多个库共同原子提交。
- 金额不擅自设 `1e15` 上限；本次保护 SQLite 整数类型、空值状态及非零方向，不把它称为完整金额引擎。合计、IPC、Excel 精度属于 M1/M4 的后续验收。
- 零金额方向随黄金样本确定，本次不从零值猜方向。
- 案号 trim 后保持原样显示；判重仅忽略 ASCII 英文字母大小写，不合并全半角或 Ä/ä。
- 本轮用户明确确认 Q08：首版只处理人民币，外币明确提示且不混入合计；该口径用于后续真实金额入口。
- 保持现有浅色视觉。介绍页单屏显示，工作台的业务内容仍允许在其内容区滚动。
- 未增加真实导入、人工复核、正式导出、自动挑选历史批次、删除备份或数据库自动修复入口。

## 2. 版本与备份

工作区和案件各有独立的 schema 版本，当前均为 v2。`code/ddl_extract_check.sql` 保留 v1 基础结构；新案由基础结构加 `hardening.cjs` 安装 v2 对象，旧案使用同一安装逻辑升级。结构校验拒绝标称版本相同但结构不符的库。

已知 v1 在校验结构、身份和旧数据后，先取得 `BEGIN IMMEDIATE` 写锁，尚未修改数据时由独立只读连接执行 SQLite `.backup()`。回读副本并核对完整性、外键、身份和行数，再在同一写事务中安装新对象、初始化摘要、修改 `user_version` 并提交。

升级产生独立备份和 manifest，保留版本、身份、校验和与结果。WAL 中已提交数据由 SQLite 备份 API 纳入。升级失败回滚；备份保留供检查，不静默替换回原库。已有违规金额、归属或大小写编号冲突会阻止升级，并报告原因，不自动改写历史业务值。

数据 worker 对请求串行 `await`，包括升级、备份和关闭。主进程停止接收关闭后的新操作，并等待已接收操作完成；不使用固定 30 秒超时提前杀掉仍在升级的 worker。

## 3. 数据保护与统计

数据库触发器覆盖金额类型、NULL pending、非零方向、案件/文件/批次归属、current/first 指针与父行改写，以及已初始化 UUID 的 UPDATE、DELETE、REPLACE、UPSERT。发布计数与任务状态等允许修改的列保留正常用途，详见代码与测试中的边界。

列表读取案件级摘要，不在刷新时对 `fund_flow` 做全量 COUNT/JOIN。摘要记录业务版本、覆盖版本、有效性和业务更新时间。打开案件只推进访问时间；schema 升级、摘要重算不冒充业务变更。

流水写入复用完整性触发器检查事务是否已将摘要标为失效；业务事务结束前统一刷新。流水表不挂逐行更新摘要的触发器。绕过正常事务直接修改流水会被拒绝；若明确标记摘要失效后自行改写，列表显示未知，不能继续展示旧数。此机制不保证防止有权限删除触发器或连同元数据一起篡改数据库。

没有材料的空案显示 0；未发布材料、损坏 current 或失效摘要显示“—”及具体原因。异常指针不自动回退到历史 done。任一案件有效流水总数未知时，工作区对应总数也未知，避免部分数量冒充完整总数。

正式查询应在同一读事务内读取有效批次与实际流水；本次仅提供基础协议与合成测试，真实导入、逐项复核和导出在后续阶段继续验收。当前 `refreshSummary` 在迁移、明确完整性检查及合成事务中全量校验回算；真实导入的批次范围维护和 19.6 万行交互性能在 M2 实施，不把这套回算写成增量导入已完成。

## 4. 目录与界面

首次选择已有合法工作区时打开原数据。非空新目录先检查，再由系统确认框说明将新建 `workspace.sqlite` 与 `cases/`；可重新选择或取消。取消不创建工作区文件。确认后携带目录检查令牌复查，等待期间出现冲突时停止，不覆盖文件。

点击进入工作台后，介绍页的节点、连接线和账页向四周退开并淡出，工作台分层浮现。过渡期间防止重复点击；返回介绍页可再次进入；减少动态效果偏好下直接切换。介绍内容按窗口高度排布，保留按钮、跳过介绍选项及说明内容。

## 6. Git 提交文案

### 步骤一：M0 加固

Summary：`加固M0版本升级、案件数据保护与统计摘要`

Description：

```text
新增工作区和案件v1到v2迁移，写锁内备份、回读校验及升级清单。
完善金额、归属、有效批次和UUID保护，使用同库统计摘要及中文异常诊断。
统一ASCII大小写案号判重，非空目录确认后复查，关闭时等待存储操作结束。
补齐升级失败、旧案保留、摘要失效、目录取消和重启回归。
```

大白话：先备份再升级，把明显错误挡在数据库外；统计不确定就说明原因，不再显示一个看似正确的零。

### 步骤二：介绍页修复与桌面交付

Summary：`修复介绍页滚动并增加进入工作台过渡动画`

Description：

```text
将介绍页收进完整视口，修复最小桌面窗口中的页面滚动。
点击进入时分散淡出介绍图形，再逐步显示工作台，保留减少动态效果支持。
更新桌面版本和交付说明，验证新便携EXE的建案、切案与重启保存。
```

大白话：首页放进一屏，点击后像翻PPT一样过渡到工作台，并重新生成可用的EXE。
