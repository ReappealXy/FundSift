# 东启勘流 HTML 交互原型

直接用外部 Chrome 打开本目录的 `index.html`。无需安装依赖、联网或启动服务。
旧版页面保存在 `index.legacy.html`，没有覆盖丢失。

## 这一版的样式

采用已选定的 A 方案：专业办公风格、浅色工作区、紧凑表格。
深蓝用于当前导航和主要操作，灰色区分层次，绿色表示已确认，琥珀色提示需要核对。
金额右对齐、数字等宽；不使用大面积渐变、装饰性图表和营销式大卡片。

## 可以体验的页面

| 页面 | 可以操作 |
|---|---|
| 案件工作台 | 案件搜索、状态分类、新建案件、切换案件、继续核查、待办跳转 |
| 材料管理 | 文件列表筛选、材料详情、查看该文件流水、添加示例材料、登记自选文件 |
| 并表流水 | 渠道/日期/金额/来源筛选、搜索、分页、多选金额汇总、紧凑行高、详情、原始记录定位 |
| 异常复核 | 金额与余额问题分类、原值对照、明确确认金额及方向、接受余额差异、记录两类处理依据 |
| 结果导出 | 范围与格式选择、内容预览、实际下载 XLSX/CSV、重新下载本次导出快照 |

推荐体验顺序：工作台 → 继续核查 → 点击一条流水 → 查看原始记录 → 异常复核 → 结果导出。
`Ctrl+K` 搜索案件与流水；`Esc` 关闭弹窗或详情。

## 数据与功能范围

- 全部为合成数据：初始 4 个案件、14 份材料、55 条流水；工作台统计来自这些记录。
- 首页日期与初始材料日期用于固定演示，新建案件和导出时间使用电脑当前时间。
- 数据保存在页面内存中，刷新后恢复初始状态。没有写入案件数据库。
- 「添加示例材料」会加入 3 条合成流水，可体验各页面的关联。
- 自选文件和拖入文件只登记名称、大小、类型，不读取文件内容，不冒充已完成真实解析。
- 待核金额使用空值，不作为零参与汇总；金额确认不会清除已有余额差异。
- 金额确认依据与余额差异依据分别保留。原始金额和方向保持不变。
- XLSX 是有效 OpenXML 工作簿，包含「并表流水」「待核清单」「导出说明」。CSV 使用 UTF-8 BOM。
- 导出保留原始字段、状态与可选来源定位；文本按文本保存，防止当作公式执行。
- 这是界面与交互原型，不代表真实解析、持久化、审计日志或百万行性能已经实现。

后续可将同一套界面接入 Electron，再连接 SQLite、解析 worker 与正式业务接口，打包为 Windows EXE。HTML 本身不等于已完成的桌面软件。正式业务规则以项目设计和核验文档为准。

## 文件组成

| 文件 | 用途 |
|---|---|
| index.html | 本地打开入口 |
| styles.css | 统一配色、排版、表格、弹窗和窄窗口布局 |
| app.js | 五页交互和页面内状态 |
| data.js | 合成案件、文件、流水和示例历史 |
| icons.js | 内联 SVG 图标，无远程字体或图片 |
| exporter.js | 无外部依赖的 XLSX/CSV 生成 |
| index.legacy.html | 原版页面备份 |
| checks/prototype.check.cjs | 离线 DOM 集成检查 |

运行原型不依赖 npm 包。开发检查脚本需要单独安装 `jsdom` 并让 Node 可以找到它；检查不需要浏览器或网络，也不读取原始案件材料。

## 本次验证

- 四个脚本均通过 Node 语法检查。
- 58 项离线 DOM 集成断言通过：五页导航、中文组合输入、搜索、筛选、分页、焦点保留、回源、新建案件、文件登记、两类异常处理、双异常状态隔离、导出及历史等。
- 实际生成的工作簿经 Python `openpyxl` 回读：38 条已确认流水与 4 条金额待核分别落表，待核标准金额为空，退款 `+1.34` 与原始 `-1.34` 同时保留。
- 导出的 CSV 行数与空值核对通过；导出模块另经 ZIP/XML 结构与公式防护检查。
- 外部 Chrome 本地页面访问被工具权限检查拒绝，因此本轮未完成浏览器实际布局、窗口尺寸和下载界面的人工验收；不能将 DOM 检查视为视觉验收。
