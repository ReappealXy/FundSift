# 东启勘流 HTML 交互原型

当前页面与桌面版 0.1.3 共用资源：网页显示合成演示说明，桌面显示真实案件管理与待开发功能说明。最新时间与任务状态验收见 [0.1.3 交付记录](../../docs/07-事务统计与任务反馈交付.md)；引导与术语见 [UI-02 交付记录](../../docs/ui-02-首屏与导入说明.md)。下文保留早期原型的设计和检查历史。

直接用外部 Chrome 打开本目录的 `index.html`。无需安装依赖、联网或启动服务。
旧版页面保存在 `index.legacy.html`，没有覆盖丢失。

现在默认先显示「软件介绍首页」，网页点击「进入示例工作台」才进入案件工作台；介绍页也可直接打开「使用说明」。
按钮旁的「下次打开跳过介绍页」勾选后，点击进入即保存选择。
想恢复时，在工作台左下角「使用说明」中勾选「打开时显示软件介绍首页」；也可以点击「查看软件介绍」重新查看。
启动偏好保存在当前浏览器，与案件演示数据分开；换浏览器、移动文件路径或清除浏览器数据后可能需要重新设置。浏览器不允许保存时仍可进入，但会明确提示无法记住选择。

## 这一版的样式

介绍页按最新确认的方向采用白色背景、淡冰蓝空间光感与蓝色操作按钮，以及带轻量轨迹动画的白色玻璃账页示意。显示多渠道汇聚、金额核验和来源定位，不用虚构的案件规模充当宣传数字。支持系统「减少动态效果」设置。标题优先使用 Noto Sans SC（思源黑体）的较粗字重，正文优先使用等线，拉丁字与步骤号使用 Bahnschrift；均为本机字体并配置后备字体，没有字体下载或切换按钮。字体调整仅作用于介绍页。

进入后的工作台采用已选定的 A 方案：专业办公风格、浅色工作区、紧凑表格。
深蓝用于当前导航和主要操作，灰色区分层次，绿色表示已确认，琥珀色提示需要核对。
金额右对齐、数字等宽；不使用大面积渐变、装饰性图表和营销式大卡片。

## 可以体验的页面

| 页面 | 可以操作 |
|---|---|
| 案件工作台 | 案件搜索、状态分类、新建案件、切换案件、继续核查、待办跳转 |
| 材料管理 | 文件列表筛选、材料详情、查看该文件流水、添加示例材料、登记自选文件 |
| 流水明细 | 渠道/日期/金额/来源筛选、搜索、分页、多选金额汇总、紧凑行高、详情、原始记录定位 |
| 异常复核 | 金额与余额问题分类、原值对照、明确确认金额及方向、接受余额差异、记录两类处理依据 |
| 结果导出 | 范围与格式选择、内容预览、实际下载 XLSX/CSV、重新下载本次导出快照 |

推荐体验顺序：介绍首页 → 进入工作台 → 继续核查 → 点击一条流水 → 查看原始记录 → 异常复核 → 结果导出。
`Ctrl+K` 搜索案件与流水；`Esc` 关闭弹窗或详情。

## 数据与功能范围

- 全部为合成数据：初始 4 个案件、14 份材料、55 条流水；工作台统计来自这些记录。
- 首页日期与初始材料日期用于固定演示，新建案件和导出时间使用电脑当前时间。
- 案件与演示数据保存在页面内存中，刷新后恢复初始状态。启动偏好单独保存，没有写入案件数据库。
- 「添加示例材料」会加入 3 条合成流水，可体验各页面的关联。
- 自选文件和拖入文件只登记名称、大小、类型，不读取文件内容，不冒充已完成真实解析。
- 待核金额使用空值，不作为零参与汇总；金额确认不会清除已有余额差异。
- 金额确认依据与余额差异依据分别保留。原始金额和方向保持不变。
- XLSX 是有效 OpenXML 工作簿，包含「流水明细」「待核清单」「导出说明」。CSV 使用 UTF-8 BOM。
- 导出保留原始字段、状态与可选来源定位；文本按文本保存，防止当作公式执行。
- 这是界面与交互原型，不代表真实解析、持久化、审计日志或百万行性能已经实现。

同一套界面已接入 Electron 和 SQLite，另有 Windows EXE，支持真实案件管理；解析 worker 与正式业务操作仍待开发。网页演示本身不等于桌面版能力。正式业务规则以项目设计和核验文档为准。

## 文件组成

| 文件 | 用途 |
|---|---|
| index.html | 本地入口、软件介绍与工作台外壳 |
| intro.css | 科技感介绍页样式与窄窗口布局 |
| intro.js | 介绍页切换、启动偏好保存与恢复 |
| copy.js | 桌面与网页模式的共享引导文案 |
| assets/fund-flow.svg | 本地动态资金轨迹主视觉 |
| styles.css | 统一配色、排版、表格、弹窗和窄窗口布局 |
| app.js | 五页交互和页面内状态 |
| data.js | 合成案件、文件、流水和示例历史 |
| icons.js | 内联 SVG 图标，无远程字体或图片 |
| exporter.js | 无外部依赖的 XLSX/CSV 生成 |
| index.legacy.html | 原版页面备份 |
| checks/prototype.check.cjs | 离线 DOM 集成检查 |
| checks/intro.check.cjs | 介绍页、启动偏好、返回路径与存储降级检查 |

运行原型不依赖 npm 包。开发检查脚本需要单独安装 `jsdom` 并让 Node 可以找到它；检查不需要浏览器或网络，也不读取原始案件材料。
