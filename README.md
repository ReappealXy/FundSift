# 东启勘流 · FundSift

面向审计与案件核查的资金流水分析桌面软件项目，供内部使用，使用私有仓库管理。

项目围绕银行、微信、支付宝等来源的流水，规划材料整理、统一并表、金额核对、异常复核、来源追溯和结果导出。目标是让每条记录保留来源，让每次确认留下依据。

**当前阶段：M0 桌面骨架。** 已把确认过的浅色界面接入 Electron，能够选择本地数据目录、新建/打开/切换案件，并保存到每案 SQLite 数据库，关闭重开后继续保留。真实流水解析、金额引擎、复核与正式导出尚未接入。

桌面版从空工作区开始，原 HTML 演示仍可单独打开。二者共用界面资源，案件数据互不混用。当前实现与验收范围见 [M0 桌面骨架与交付](docs/05-M0桌面骨架与交付.md)。

## 使用桌面版

双击已生成并通过建案、重启验证的 [FundSift-0.1.0-win-x64.exe](dist/FundSift-0.1.0-win-x64.exe)。首次进入工作台时选择案件数据保存目录，再填写案件名称与案件编号。选择目录不会移动或导入原始案件材料。

案件数据放在所选目录；软件启动选择等设置放在本机用户配置目录。重新打开软件会读取已有工作区。M0 中材料、并表、复核与导出页面明确显示尚未接入，不会把演示记录当作真实业务结果。

## 开发与打包

开发环境需要 Node.js（本轮使用 22.20.0）、npm 和 Windows x64。依赖由 `package-lock.json` 固定；SQLite 原生组件须使用 Electron 对应 ABI，普通 Node 不能直接代替桌面运行环境加载它。

在仓库根目录运行：

```powershell
npm ci
npm start
```

检查与打包：

```powershell
npm test
npm run smoke
npm run build
```

`npm test` 包括 HTML 回归、桌面桥接合同与真实 SQLite 存储测试；`smoke` 使用独立临时目录启动桌面程序、建案并重启，不读取真实案件。本次交付已完成便携 EXE 烟测；以后重新打包，也需对新产物执行同样检查，具体命令与结果见 [M0 交付记录](docs/05-M0桌面骨架与交付.md)。

依赖安装/打包需联网获取官方运行时和原生预编译包；运行桌面版不需要联网。`node_modules`、`dist`、运行产物、数据库和样本目录已排除在 Git 之外。

## 单独体验 HTML 演示

1. 将仓库下载到本地，保留目录结构。
2. 使用外部 Chrome 打开 [code/prototype/index.html](code/prototype/index.html)。无需安装依赖、联网或启动服务。
3. 在软件介绍首页点击「进入工作台」，体验案件与流水处理流程。

介绍首页采用白色与淡冰蓝配色，配合动态资金轨迹；进入后的工作台采用紧凑、清晰的办公界面。

「下次打开跳过介绍页」在点击进入时保存选择。如需恢复，在工作台左下角「使用说明」中勾选「打开时显示软件介绍首页」；点击「查看软件介绍」也可重新查看。

HTML 的启动选择保存在当前浏览器。换浏览器、移动文件位置或清除浏览器数据后，可能需要重新设置；它与桌面版用户配置分开。

## HTML 演示中的交互

| 页面 | 已实现的原型交互 |
|---|---|
| 软件介绍首页 | 软件介绍、资金轨迹示意、功能概览、使用流程、进入工作台、启动跳过与恢复 |
| 案件工作台 | 新建与切换示例案件、案件搜索、状态分类、待办跳转 |
| 材料管理 | 文件列表与详情、渠道筛选、登记自选文件信息、添加示例材料 |
| 并表流水 | 搜索、渠道/日期/金额/来源筛选、分页、多选汇总、记录详情与来源定位示意 |
| 异常复核 | 对照原值、人工确认金额与方向、单独处理余额差异、填写处理依据 |
| 结果导出 | 选择范围、预览内容、生成并下载有效 XLSX/CSV 文件、重新下载本次导出快照 |

推荐体验路径：**介绍首页 → 案件工作台 → 并表流水 → 点击记录查看来源 → 异常复核 → 结果导出**。

工作台支持 `Ctrl+K` 搜索；`Esc` 关闭弹窗或流水详情。

## 原型的数据与边界

- 工作台使用完全虚构的合成数据，用来确认界面与操作流程，不代表真实案件的处理结果。
- 演示案件、文件登记和复核结果保存在页面内存中，刷新后恢复初始状态；启动偏好单独保存在浏览器中。
- 自选或拖入的文件只登记名称、大小与类型，尚不读取和解析文件内容。「添加示例材料」用于体验模拟并表流程。
- 金额待核的标准金额保持空值，不作为零计入收支汇总。确认金额与处理余额差异分别保存状态和依据。
- 来源查看目前展示合成记录的位置与字段，尚未接入真实 Excel、CSV 或 TXT 文件的原件定位。
- XLSX/CSV 下载可以实际使用，导出内容来自当前演示记录。该导出实现用于原型体验，尚未验证百万行生产性能。

## 后续开发方向

| 方向 | 当前状态与计划 |
|---|---|
| 桌面运行与安装包 | 已接入 Electron 桌面壳和 Windows 打包命令，产物验收见 M0 交付记录 |
| 案件数据保存 | 已实现工作区索引、每案 SQLite、两个字段建案与重启保存；编辑/归档/删除未开放 |
| 流水解析与金额处理 | 按已核验的格式、单位、方向与冲突规则实现真实解析及金额引擎 |
| 后台任务 | 数据库操作已在 utilityProcess worker；解析与长任务在后续阶段接入 |
| 回源、审计与验收 | 接入真实来源坐标、规则版本、批次管理与正式操作记录，完成样本及规模验收 |

具体实施范围和验收要求以设计与开发计划为准。HTML 原型中的演示行为不替代最终业务规则。


## 已完成的检查

M0 已执行 15 组真实 SQLite 存储测试、42 项桌面桥接合同检查；原有 42 项介绍与启动偏好检查、58 项工作台检查保持通过。开发态和最终便携 EXE 均通过建案、重启两阶段烟测，已验证界面建案写库、拒绝重复编号、关闭重开后数据保留，以及数据目录失联时拒绝在原处重建空工作区、目录恢复后可重新打开。

HTML 示例导出的 XLSX 曾经结构解析与回读验证，CSV 行数与待核空值也已核对；这些结果属于演示导出，不能当作正式导出验收。

完整测试、桌面截图及打包交付记录见 [M0 交付记录](docs/05-M0桌面骨架与交付.md)。本阶段尚不证明真实案件流水处理、百万行性能、正式复核或导出能力。
